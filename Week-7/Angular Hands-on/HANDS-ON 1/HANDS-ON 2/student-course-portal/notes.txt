1. angular.json
Stores the Angular project configuration such as build, serve, test, and project settings.

2. tsconfig.json
Main TypeScript configuration file used by the Angular project.

3. tsconfig.app.json
TypeScript configuration specifically for the application source files.

4. package.json
Contains project metadata, dependencies, scripts, and npm package information.

5. src/main.ts
Entry point of the Angular application. It bootstraps the root application.

6. src/app/app.config.ts
Configures the Angular application using the standalone API (Angular 17+).

7. src/app/app.component.ts
Defines the root component of the Angular application.

8. src/index.html
Main HTML page where the Angular application is loaded.
